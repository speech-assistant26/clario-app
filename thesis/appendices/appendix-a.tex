\section{Model Training Code}
\label{app:training-code}

Listing~\ref{lst:app-train} gives the construction and training of the selected
CNN--BiLSTM classifier, including the split-before-balance ordering discussed in
Section~\ref{sec:split}.

\begin{lstlisting}[language=Python, caption={Split, class balancing and CNN--BiLSTM training.}, label={lst:app-train}]
# ---- SPLIT FIRST, then balance ONLY the training set ------------------
# Balancing before splitting leaks upsampled duplicates into the test set
# and inflates every reported metric. Split first; the test partition
# keeps the natural 15% / 85% distribution.
y_cat_all = to_categorical(y, num_classes=2)
X_train_raw, X_test, y_train_raw, y_test = train_test_split(
    X, y_cat_all, test_size=0.2, random_state=RANDOM_STATE, stratify=y)

# Upsample the minority class within the TRAINING partition only.
y_train_lbl = np.argmax(y_train_raw, axis=1)
X_tr_err = X_train_raw[y_train_lbl == 1]
X_tr_ok  = X_train_raw[y_train_lbl == 0]
X_tr_err = resample(X_tr_err, replace=True, n_samples=len(X_tr_ok),
                    random_state=RANDOM_STATE)

X_train = np.concatenate([X_tr_err, X_tr_ok])
y_train_bal = np.concatenate([np.ones(len(X_tr_err)), np.zeros(len(X_tr_ok))])
perm = np.random.RandomState(RANDOM_STATE).permutation(len(X_train))
X_train = X_train[perm]
y_train = to_categorical(y_train_bal[perm], num_classes=2)

# ---- CNN-BiLSTM -------------------------------------------------------
inp = Input(shape=X_train.shape[1:])                 # (64, 32, 1)
x = Conv2D(16, (3, 3), activation="relu", padding="same")(inp)
x = BatchNormalization()(x); x = MaxPooling2D((2, 2))(x); x = Dropout(0.3)(x)
x = Conv2D(32, (3, 3), activation="relu", padding="same")(x)
x = BatchNormalization()(x); x = MaxPooling2D((2, 2))(x); x = Dropout(0.3)(x)
x = TimeDistributed(Flatten())(x)                    # (16, 256)
# No recurrent_dropout: it disqualifies the layer from the fused cuDNN
# kernel and costs roughly an order of magnitude in epoch time.
x = Bidirectional(LSTM(128, dropout=0.3))(x)
x = Dense(64, activation="relu")(x); x = Dropout(0.3)(x)
out = Dense(2, activation="softmax")(x)

model = Model(inp, out)
model.compile(loss="categorical_crossentropy", optimizer="adam",
              metrics=["accuracy"])

early_stop = tf.keras.callbacks.EarlyStopping(
    monitor="val_loss", patience=5, restore_best_weights=True)
history = model.fit(X_train, y_train, batch_size=BATCH_SIZE, epochs=EPOCHS,
                    validation_data=(X_test, y_test), callbacks=[early_stop])
\end{lstlisting}

\section{Inference Pipeline Code}
\label{app:inference-code}

Listing~\ref{lst:app-infer} gives the top-level analysis method of the deployed
service. It is a faithful port of the notebook inference cell, batched into a
single framework call.

\begin{lstlisting}[language=Python, caption={Top-level analysis method of the inference service.}, label={lst:app-infer}]
def analyze(self, wave, target_word, error_threshold=None):
    """Per-phoneme results for a pre-trimmed waveform + its target word."""
    self.load()
    segments = self.align(wave, target_word)
    if not segments:
        return []

    threshold = (error_threshold if error_threshold is not None
                 else self.s.error_threshold)

    # One mel patch per phoneme, classified in a single batched predict.
    mels = np.stack([self.crop_mel(wave, s, e) for _, s, e, _ in segments])
    mels = mels[..., np.newaxis]            # (n_phon, n_mels, frames, 1)
    mels = self._normalize(mels)            # training-exact global z-score
    probs = self._clf.predict(mels, verbose=0)[:, 1]     # P(error)

    results = []
    for (phon, s, e, align_sc), p in zip(segments, probs):
        p = float(p)
        results.append({
            "phoneme":     phon,
            "start":       round(s, 4),
            "end":         round(e, 4),
            "verdict":     "ERROR" if p >= threshold else "ok",
            "error_prob":  round(p, 4),
            "align_score": round(align_sc, 4),
        })
    return results
\end{lstlisting}

\section{Deployment Reference}
\label{app:deployment}

\subsection{Local development}

\begin{lstlisting}[caption={Running the full stack locally with Docker Compose.}, label={lst:app-compose}]
# From the repository root. Builds the API and the nginx-served web app,
# mounts the trained model read-only, and persists the aligner download
# in a named volume so later starts are fast.
docker compose up --build

#   web app : http://localhost:3000
#   API     : http://localhost:8010
#   health  : curl http://localhost:8010/api/health
\end{lstlisting}

\subsection{Single-image production deployment}

The production image builds the frontend with Node, installs the backend with
CPU-only PyTorch wheels, optionally pre-fetches the aligner and Whisper models
into an image layer, and serves both the API and the compiled static assets from
one Uvicorn process on port 8000. Because the API and the UI share an origin, no
CORS configuration is required, and the HTTPS origin satisfies the browser's
secure-context requirement for microphone access.

\subsection{Health endpoint}

\begin{lstlisting}[caption={Health endpoint response for a fully ready service.}, label={lst:app-health}]
{
  "status": "ok",
  "model_loaded": true,
  "align_model_loaded": true,
  "whisper_loaded": true,
  "espeak_available": true,
  "device": "cpu",
  "normalization": "global-zscore"
}
\end{lstlisting}

\noindent
The \texttt{normalization} field is the field to check after any deployment: a
value of \texttt{per-clip-zscore} indicates that neither the environment
override, the dataset archive nor the baked-in constants were resolved, and that
the service is running at reduced accuracy.
